# Decision records

Short records of decisions that are settled, and _why_. They exist so nobody — human or agent —
spends an afternoon relitigating a choice that was already made deliberately.

A decision here is not permanent, but reopening one should mean engaging with the recorded
reasoning, not rediscovering it. If you change a decision, supersede the record rather than
deleting it.

Format: context → decision → consequences → how we'd know we were wrong.
